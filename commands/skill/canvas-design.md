# 视觉艺术设计

以设计哲学驱动创作海报、传单、单图视觉稿，输出 PNG/PDF。

<objective>
先写视觉哲学宣言（命名流派+美学论述），再据此在画布上视觉化表达，产出高质量单图设计。
</objective>

<rules>
- 先加载 canvas-design 技能获取完整创作流程
- 字体从技能自带 canvas-fonts/ 目录选择，排版参与构图
- 元素不重叠不出界，改稿靠精炼既有构图而非堆新图形
- 一切面向用户的文案使用中文
</rules>

<process>
1. 理解设计需求（营销页视觉稿/海报/封面）
2. 撰写视觉哲学宣言
3. 画布视觉化，输出 PNG（或 PDF）
4. 自审：留白/边界/构图聚合度
</process>
