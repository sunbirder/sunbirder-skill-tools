# doc-gen

根据项目代码生成完整且相互独立的开发文档集 — 每个流程独立成篇，配备完整图表。

## 触发条件

- 输入 `/skill:doc-gen`
- 说 "生成项目文档" 或 "帮我给这个项目写文档"

## 流程

1. **项目分析** — 扫描 package.json、目录树、源码、配置，枚举所有开发流程、功能流程、模块
2. **确定文档清单** — 一个流程一份文档，用户确认
3. **逐份生成** — 每份文档独立成篇，图表完整（覆盖分支与异常路径）
4. **完整性自检** — 对照清单检查每个流程都有独立文档
5. **注册到文档站** — 更新 VitePress 侧边栏，按分类分组

## 文档分类

| 分类 | 文档 |
|------|------|
| 总览类 | 项目概述、架构总览、目录结构 |
| 开发流程类 | 环境搭建、日常开发、构建、测试、发布、部署（每个流程独立一份） |
| 功能流程类 | 每个核心功能独立一份 |
| 参考类 | API/命令参考、配置说明、FAQ |

## 文档质量标准

- **独立成篇** — 一份文档只讲一个流程/主题，相关内容拆分互链，禁止堆叠
- **图表完整** — 每份至少一张 Mermaid 图，覆盖主流程 + 分支 + 异常路径（不能只画 happy path）
  - 流程 → flowchart 流程图
  - 架构 → 模块架构图
  - 多方调用 → sequenceDiagram 时序图
  - 状态变化 → stateDiagram-v2 状态图
  - 数据模型 → erDiagram 实体关系图
- 有实际代码引用（文件路径：行号）
- 有可运行的代码示例
- 覆盖异常场景与排查方法

## 与 docs-sync 的区别

| 维度 | doc-gen | docs-sync |
|------|---------|-----------|
| 场景 | 新建文档、从头生成 | 更新已有文档 |
| 范围 | 全项目、全部流程 | 按需/增量 |
| 产出 | 完整独立文档集 | 修正后文档 |
