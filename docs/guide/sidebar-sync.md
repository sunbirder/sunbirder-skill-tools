# sidebar-sync

VitePress 侧边栏同步 — 文档文件生成了，但站点菜单里看不到？扫描 docs 全部 Markdown 文件与 config 已注册条目的差异，补齐缺失菜单入口、清理死链。

## 触发条件

- 输入 `/skill:sidebar-sync`
- 说 "文档菜单没有入口"、"新文档没加到侧边栏"、"同步侧边栏"

## 解决的问题

| 问题 | 现象 |
|------|------|
| 未注册 | 文档文件存在，但侧边栏/导航里没有入口，页面无法到达 |
| 死链 | 菜单里有条目，但文件已改名/删除，点击 404 |
| 错组 | 条目存在但分组或排序不合理 |

## 流程

1. **扫描文档清单** — find 全部 .md（排除 node_modules/dist/cache），提取标题
2. **解析已注册条目** — 从 config 提取 nav/sidebar 全部 link（外链跳过）
3. **对比差异表** — 未注册 / 死链 / 错组，三类问题列清单
4. **确认修正策略** — 分组规则、标题规则、排序规则、死链处理方式先给用户确认
5. **修改配置并复验** — 最小改动；复扫 diff 为空才算完成，报告增/改/删条数

## 原则

- 文件为准 — 所有公开文档页面都必须能从菜单到达
- 最小改动 — 只增删必要条目
- 先确认再改
- 复验收尾 — diff 为空才算完成
