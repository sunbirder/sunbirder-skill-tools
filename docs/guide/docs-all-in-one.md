# docs-all-in-one

一站式 web 文档 — 生成完整独立的开发文档集，并搭建为可浏览的 VitePress 文档站。等于 `/skill:doc-gen` + `/skill:vitepress-doc-site` 一次完成。

## 触发条件

- 输入 `/skill:docs-all-in-one`
- 说 "一站式生成文档站"、"生成文档并搭建成网站"

## 流程

1. **项目分析** — 枚举开发流程、功能流程、模块三份清单
2. **确定文档清单** — 一个流程一份文档，用户确认
3. **搭建文档站骨架** — 端口分配（5173 起间隔 10）、package.json、config.ts（withMermaid）、首页、主题
4. **逐份生成文档** — 写入 docs/，每份独立成篇、图表完整（覆盖分支与异常路径）
5. **完整性自检 + 注册侧边栏** — 对照清单检查，按分类注册到 config.ts
6. **启动预览** — `cd docs && npm run dev`，报告访问地址

## 与单独使用两个技能的区别

| 维度 | doc-gen + vitepress-doc-site 分开调用 | docs-all-in-one |
|------|--------------------------------------|-----------------|
| 调用次数 | 2 次 | 1 次 |
| 顺序协调 | 需自行安排 | 内置：先定清单 → 建骨架 → 生成文档 → 注册 → 预览 |
| 适用场景 | 已有站补文档 / 已有文档搭站 | 新项目从零到可浏览文档站 |

## 文档质量标准

与 doc-gen 相同：

- 独立成篇 — 一份文档只讲一个流程/主题
- 图表完整 — 每份至少一张 Mermaid 图，覆盖主流程 + 分支 + 异常路径
- 代码引用、可运行示例、异常场景与排查方法
