# 提问剧本（Step 01 与各步澄清共用）

## 两个流派

**A · 苏格拉底式一次一问**（superpowers brainstorming）：需求极模糊、对方也没想清楚时用。一次一问，每次回答后写回你的理解（区分"对方说的"与"你的假设"）邀请纠错。

**B · 决策树前沿批量问**（mattpocock grilling，默认用）：把方案画成决策树，每轮把"前沿"（前置已定的全部问题）编号抛出，每问给选项 + 推荐答案（措辞让"对"= 接受推荐）。分工铁律：**事实自己查（代码库/文档/数据），决策才问人**；某问依赖的事实在查，只推迟那一支。终止条件：前沿清空 + 用户确认共识。

## 每轮格式

```
❓ Q1 〈问题标题〉：<问题正文，可含多段>
   A) … B) … C) …
   ➡️ 推荐：A，因为 …
（一轮最多 4 问）
```

## 通用 16 问骨架（全流程提问的地图）

R1 基础：名称 / 类型 / 目标用户（列角色，追问年龄与技术程度）/ 一句话描述
R2 问题：解决什么 / 现在怎么应付 / 为什么现在做 / 最常抱怨
R3 范围：用户量级 / 必做功能（3-5）/ 可后置 / 明确不做
R4 度量约束：成功指标（用完什么变了）/ 期限 / 技术约束 / 输出语言
R5 触发式（默认跳过，命中才问）：收费→商业模式；存证件/健康/金融数据→合规与"能否存境外云"；第三方→集成；非本人运维→维护

## 澄清 6 维度（对任何已有材料补刀用）

①目标可量化吗（有数字吗？反指标？）②场景真实吗（谁/情境/频率/现状）③边界清晰吗 ④优先级对吗（P0 >5 条吗？砍谁仍可用？）⑤约束漏了吗（技术/合规/时间/依赖）⑥证据充分吗（哪些是无证据观点驱动）

## 禁忌

诱导与假设性问题（"如果有 X 你会用吗"）；是非题（"是不是很难"）；一次 >4 问；问能自己查的事实；替用户拍板。
